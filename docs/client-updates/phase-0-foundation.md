# Phase 0: Foundation

**Status: ✅ Done**

## What this phase built

Before any pages or products could go up, the site needed a solid foundation to build on. This phase set up:

- **The color palette** — the warm dark background (inspired by tarmac/asphalt), the red accent color (named after Kenya's red rally roads), and the sandy light background used for product pages. These colors are locked in as reusable building blocks, so every future page automatically stays on-brand without anyone having to eyeball-match colors by hand.
- **The fonts** — a bold heading font for headlines, a clean readable font for body text and prices, and a special stencil-style font reserved for small numeric details (like a rally car's door number) that echo the motorsport theme.
- **The toolkit** — the underlying software framework the whole site runs on, plus a library of pre-built, accessible interface components (menus, buttons, pop-ups) that come with correct keyboard and screen-reader support built in, rather than being built from scratch.

## Why it matters

This is the equivalent of pouring a foundation before framing a house — nothing visible to a customer yet, but it means every page built from here on shares the same look, feel, and quality baseline automatically. It also means accessibility (people who navigate by keyboard or screen reader) is handled correctly from day one, not bolted on at the end.

## What's not visible yet

There's no real homepage or shop yet — just a placeholder page confirming the foundation works. That starts with Phase 3.
